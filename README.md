# Editor Together

Experimental real-time collaborative editor support for A Dance of Fire and Ice.

This repository contains an early prototype. Use at your own risk and keep backups of important charts.

## Components

- `src/EditorTogether` — Unity Mod Manager client mod.
- `src/EditorTogether.Server` — ASP.NET Core collaboration relay / asset server.

## Notes

The current prototype is under active development on feature branches. Protocol and behavior may change between versions.
